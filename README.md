# AI 新手陪练 · AI Beginner Coach

**先听你准备怎么做，再根据你的理解，一步一步带你真正用起来。**

简体中文 · [English](README.en.md)

面向完全不懂技术的 AI 使用者的 Agent Skill。可以带你学工具、用 AI 搜资料，或把搜索、整理、写作串成一个可重复的工作流程。

当前版本：**v0.5.0** · [MIT 许可证](LICENSE)

## v0.5：入口、目标保持与步骤检查

指定工具与练习任务分别保存。“用 Ego Lite 打开测试网站”不会因为后续“帮我打开”变成提供普通链接；“直接帮我做”只改变协作方式。执行前核实安装、启动与连接，完成时要求对应工具的实际结果记录。见 [任务协议](references/task-contract.md)。

程序能检查状态、证据字段、步骤顺序和环境标识；不能证明助手提交的证据真实，也不能拦截绕过检查器的工具调用。Claude 项目 hook 可逐轮恢复任务状态；其他客户端按 Skill 指令恢复。没有任意 Agent 永不偏离的保证。

### 项目级安装与自检（Node.js 18+）

从下载的本项目目录执行，替换项目路径：

```text
node scripts/install-local.cjs --project "你的工作项目路径" --client claude
node scripts/install-local.cjs --project "你的工作项目路径" --client codex
node tests/coach-state.test.cjs
```

按实际客户端选择一条安装命令。Claude 安装到 `.claude/skills/ai-beginner-coach` 并追加每轮状态 hook；Codex 安装到 `.agents/skills/ai-beginner-coach`。既有同名目录会拒绝覆盖，需先比较版本。安装命令会保留既有 Claude 设置并备份。仅复制文件不是客户端已加载的证据；请在新任务中核对 Skill 路径和状态记录。

状态保存在工作项目 `.ai-beginner-coach/sessions/`，含用户任务信息，请勿提交到公共仓库。脚本不安装 Ego Lite，不替用户迁移浏览数据。

## 它解决什么问题

拿到一个 GitHub 链接，听说工具很好用，却不知道它能帮自己做什么；下载之后，不清楚应该在哪个窗口向 AI 发任务；知道几个软件的名字，却不知道它们怎么配合。

这个 Skill 让 AI 先听你的打算，找到具体卡点，再带着做一个真实的小任务。它会区分：

- 你还没理解工具之间的关系。
- 你已经理解，只是不认识按钮或不会执行某一步。
- 你用的软件缺少需要的能力。
- 你知道怎么做，只是希望 AI 帮忙完成机械操作。

它不会仅凭一句“懂了”就判断你已经学会，也不会因为你说不出专业术语就从头讲一遍。

## 对话会怎样开始

**你：** 朋友推荐了 Ego Lite，这个项目怎么用？

**陪练：** 你现在打算怎么用它？先说说你觉得第一步该做什么，想到哪说到哪就行，完全没想法也没关系。

然后根据回答改变教法：

| 你的回答 | 陪练接下来做什么 |
|---|---|
| “完全不知道。” | 给一个小例子和最小起点，不继续逼你猜。 |
| “下载装好，然后给 AI 用。” | 只追问一个关键断点，例如准备在哪里发任务。 |
| “在 Ego 里面跟 AI 说话。” | 先确认是地址栏、聊天网站还是其他入口，不直接判错。 |
| “我懂助手和浏览器的关系，只是不认识下载按钮。” | 帮你选按钮，跳过已懂的概念。 |
| “我知道要把资料交给第二个 AI，但整理好麻烦。” | 帮你整理交接材料，降低操作负担。 |

教学过程：**听思路 → 澄清关键点 → 针对性解释 → 做一个小动作 → 核对结果 → 留下复用方法。**

“先问思路”不是强制考试：你已经说过就不重复问；你明确说没想法就开始带做；你要求直接帮忙时，也可以切换成“帮我做并解释”。

## 三类使用场景

1. **工具与项目上手**：GitHub 项目、网站、桌面应用、插件或其他 Skill。Ego Lite 是完整教学案例，具体安装步骤会依据当前官方说明核实。
2. **AI 搜索**：明确问题、获取来源、核对原文、理解免费额度与功能限制，区分有链接和有证据。
3. **工作流程**：把资料交给下一步，连接搜索、整理、写作等任务；先跑通一次，再判断是否需要自动化。

## 安装

### 已有支持 Skill 的 AI 客户端

使用 [Skills CLI](https://github.com/vercel-labs/skills) 安装：

```bash
npx skills add hellanglla/ai-beginner-coach
```

在终端运行，按提示选择你实际使用的 AI 客户端。默认安装到当前项目；希望跨项目使用时加 `-g`：

```bash
npx skills add hellanglla/ai-beginner-coach -g
```

截至本版说明核对时，Skills CLI 要求 Node.js 22.20 或以上；最新要求与支持的客户端以其[官方说明](https://github.com/vercel-labs/skills#install-a-skill)为准。这个要求来自安装器，Skill 本身是一组 Markdown 指令，无需编译。

如果不想用 CLI，可下载本仓库，将包含 `SKILL.md`、`references/` 和 `agents/` 的文件夹放到客户端当前支持的 Skill 目录，并命名为 `ai-beginner-coach`。目录位置依客户端而异；不要只复制 `SKILL.md` 而漏掉参考文件。安装后按客户端要求重新发现 Skill 或开启新会话。

### 不知道终端是什么，或者暂时不能安装

先把下面这段复制给你正在使用的 AI，就能体验简版教法。**这不等于完整 Skill 已安装。**

```text
请当我的 AI 新手陪练。先问我准备怎么做，等我说完再教。
根据我的原话区分已理解的部分、未知点和具体误解，不打分，也别把没提到的内容都当成不懂。
说对的部分沿用；含糊的地方只追问一个关键点；有误解就用一个小例子解释。
如果我完全没想法，就给我一个具体起点；如果我想让你直接帮忙，就在实际能力范围内帮我做并解释。
不要把我打算做的事当成已经做完，也不要把举例里的数字当成真实要求。
每次带我做一个有清晰结果的小动作，告诉我在哪操作、怎样算成功。
必要时换个情境看看我是否会应用，别只问“懂了吗”。完成后留下下次可复用的方法。
不能联网或控制电脑时请直说，不要假装已查过或已操作。
```

## 开始使用

安装后，在支持名称调用的客户端中发送：

```text
请用 $ai-beginner-coach 教我使用这个项目：https://github.com/citrolabs/ego-lite
先听我的思路，再带我完成第一次真实使用。
```

```text
请用 $ai-beginner-coach 教我用 AI 搜索免费的图片整理工具。
先看看我打算怎样查，再教我核对来源和限制。
```

```text
请用 $ai-beginner-coach 带我把搜资料、整理要点、写文章串起来。
先让我说一下自己的步骤，再帮我补上没想明白的部分。
```

如果客户端不支持 `$名称` 语法，用自然语言要求“使用 AI 新手陪练 Skill”，或按其文档选择此 Skill。调用方式以客户端支持为准。

## 能力与边界

- Skill 规定 AI 怎样教，不会自动赋予联网、终端或电脑控制权限。没有相应工具时会改成手动带做，或说明缺少什么。
- 安装成功、生成摘要、完成实际任务是不同状态；指定用 Ego Lite 时，其他搜索工具的结果不算浏览器连通证据。
- 支持暂停与续接。有文件能力时可保存进度；否则提供可复制的续学卡，不承诺未保存的进度会永久保留。
- 安装本 Skill 不会安装 Ego Lite 或其他案例软件。购买、对外发送、发布和迁移账号数据等操作应按用户的具体授权处理。
- 核心指令和参考文件目前以中文编写，但要求 AI 使用学习者的语言。英文 README 不代表全部教学材料已翻译或完成英文场景测试。

## 测试状态

最近一轮采用分角色多轮模拟：陪练看不到新手的隐含状态，收到逐轮回答后再选择下一步。v0.3.0 基线有 32 条回复，v0.4.0 初稿复测有 16 条，最后一次窄修正另做 1 条独立冷启动检查。

这些测试发现并推动修复了计划/完成状态混淆、过早肯定理解、假设参数进入真实需求等问题。**这是模拟行为测试，不是真人学习效果或全新电脑安装成功率证明。** 当前环境的历史浏览器运行验证与本轮教学测试分开记录。

方法、结果和限制见[测试说明](docs/VALIDATION.md)。维护者可用 [scenarios.md](references/scenarios.md) 中的情境继续检查行为。
